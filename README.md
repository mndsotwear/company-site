# سایت شاهین مارین (Next.js + Payload CMS)

بازسازی سایت shahinmarine.com. سند کامل برنامه: https://claude.ai/artifact/7SoX44LeqsHwe6M2xA37SX

## وضعیت فعلی: فاز ۱ (پایه‌ی پروژه)

- پنل مدیریت Payload با کاربران (مدیر / ویرایشگر)، رسانه و تنظیمات سایت
- دو زبان فارسی (`/fa`) و انگلیسی (`/en`) با راست‌چین و چپ‌چین خودکار
- تم تیره و روشن با دکمه‌ی ماه/خورشید
- هدر، منوی موبایل، فوتر، دکمه‌ی شناور استعلام
- صفحه اصلی اولیه: هیرو، رهگیری سریع، نوار بنادر

صفحات دیگر (خدمات، کشتی‌ها، رهگیری، ...) هنوز ساخته نشده‌اند و فعلاً خطای ۴۰۴ می‌دهند.

## اجرای پروژه

### ۱. دیتابیس (DBngin)

در برنامه‌ی **DBngin** سرویس **`shahin-marine`** (PostgreSQL 18.4، پورت **5433**) را Start کنید.
کاربر `postgres` بدون رمز است (پیش‌فرض DBngin). سرویس‌های lujan روی پورت 5432 هستند و تداخلی ندارند.

### ۲. سایت

در ترمینال VS Code:

```
npm run dev
```

یا در پوشه‌ی `scripts` روی `2-start.bat` دو بار کلیک کنید.

- سایت: http://localhost:3000 ، پنل مدیریت: http://localhost:3000/admin
- خاموش کردن: Ctrl+C در ترمینال

### اسکریپت‌ها

| فایل / دستور | کار |
| --- | --- |
| `npm run db:create` | ساخت دیتابیس `shahin_marine` در DBngin (اگر نباشد) |
| `scripts/0-check.bat` | بررسی Node، npm و ابزارهای نصب‌شده |
| `scripts/1-install.bat` | نصب پکیج‌ها + ساخت دیتابیس |
| `scripts/1b-approve-scripts.bat` | اجازه به اسکریپت‌های نصب sharp و esbuild (npm 12) |
| `scripts/2-start.bat` | اجرای سایت |
| `scripts/3-get-hero.bat` | دانلود عکس هیرو از سایت فعلی |

### نسخه‌ها

Next.js 16.4.5، Payload 3.93.0، Node.js 24 (نسخه‌ی پیشنهادی Payload: ۲۴.۲۲ به بالا؛ نسخه‌ی فعلی ۲۴.۱۵ فعلاً مشکلی ندارد)

## ساختار پوشه‌ها

```
src/
  app/(frontend)/[locale]/   صفحات سایت (fa و en)
  app/(payload)/             پنل مدیریت و API (فایل‌های استاندارد Payload)
  collections/               بخش‌های پنل (کاربران، رسانه، ...)
  globals/                   تنظیمات یکتا (تنظیمات سایت)
  access/                    قوانین دسترسی نقش‌ها
  components/                قطعات ظاهری (هدر، فوتر، دکمه تم، ...)
  i18n/                      تنظیمات دو زبانه
  styles/globals.css         رنگ‌های دو تم و فونت
messages/fa.json, en.json    متن‌های ثابت سایت
public/images/               عکس‌ها (hero.webp از سایت فعلی)
```

## کارهای دستی شما

- اگر فونت‌های ایران‌یکان و پیدا را دارید، فایل‌های woff2 را در `public/fonts` بگذارید و خبر بدهید
